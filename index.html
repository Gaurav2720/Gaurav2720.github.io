03 — How the work gets done

Build. Break. Document.

  1. 01

    Read the spec

    Start from the actual requirement — routes, inputs, status codes, and edge cases — before touching a single file.

  2. 02

    Build the thin slice

    Get one request working end-to-end. Server, route, data, response. Then layer validation, sessions, and persistence.

  3. 03

    Test like an attacker

    Postman, DevTools, bad payloads, missing cookies. The happy path is the easy part; the failures teach the design.

  4. 04

    Write it down

    Every lab ends with a report: aim, approach, code structure, observations. If it isn't written, it isn't finished.
